# Wireless Environmental Monitoring System

ESP32-based environmental monitoring system that collects temperature, humidity, and atmospheric pressure data and transmits the measurements over Wi-Fi to a computer for storage and visualization.

## Planned Architecture

BME280 Sensors => ESP32 => Wi-Fi => Computer / Server => SQLite => Dashboard

## Main Hardware

- ESP32 development board
- BME280 environmental sensor

## Technologies

- C/C++
- ESP32
- I2C
- Wi-Fi
- SQLite
- Data visualization
